# Contributing to This Project

👋 Welcome!  
Thank you for considering contributing. This is my first open-source project, so I want to keep the process simple and beginner-friendly.

---

## How You Can Contribute
There are many ways to help:
- 🐛 Report bugs
- 💡 Suggest new features
- 🛠️ Improve code
- 📖 Improve documentation (README, comments, etc.)

---

## Getting Started
1. **Fork this repository**  
   (Click the **Fork** button on the top-right of this page)

2. **Clone your fork locally**
   ```bash
   git clone https://github.com/pravenjadhav1510/save-links.git
   cd save-links
   ```

3. **Create a new branch** (don’t work directly on `main`)  
   ```bash
   git checkout -b feature/your-feature-name
   ```

4. **Make your changes**  
   - Write clear, simple code  
   - Add comments if needed  
   - Test your changes  

5. **Commit your changes**  
   ```bash
   git add .
   git commit -m "Add: short description of changes"
   ```

6. **Push your branch**
   ```bash
   git push origin feature/your-feature-name
   ```

7. **Open a Pull Request (PR)**  
   - Go to your fork on GitHub  
   - Click **Compare & pull request**  
   - Write what you changed and why  

---

## Code Style
- Keep the code clean and readable  
- Use meaningful variable and function names  
- Follow the existing project style (don’t reinvent unless necessary)  

---

## Issues
- If you find a bug, please open an **Issue** on GitHub  
- Clearly describe the problem and how to reproduce it
